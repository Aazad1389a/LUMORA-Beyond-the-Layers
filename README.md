# LUMORA: Beyond the Layers

بازی پلتفرمر دوبعدی فارسی ساخته‌شده با HTML5 Canvas — خروجی نهایی فقط یک فایل HTML است و به نصب نیاز ندارد.

🎮 **بازی آنلاین (GitHub Pages):** https://aazad1389a.github.io/LUMORA-Beyond-the-Layers/

## ویژگی‌ها
- ۴ لایه‌ی متمایز — مادی، انرژی، وارونه، سایه — هرکدام با مکانیک و سبک بصری خودش
- سیستم NEXORA برای جابه‌جایی تعاملی بین لایه‌ها
- چندنفره‌ی واقعی P2P با PeerJS و بدون سرور: حالت‌های Dodge / Hunt / Race با کد اتاق
- حالت بی‌نهایت (Infinite) با سختی فزاینده
- فروشگاه توانایی، سختی پنهانِ تطبیقی (DDA) و ذخیره‌ی خودکار پیشرفت
- موسیقی و افکت‌های صوتی تولیدشده با WebAudio — بدون هیچ فایل صوتی
- افکت‌های Juice: پارتیکل، لرزش دوربین، اسلوموشن و ...
- رابط فارسی راست‌به‌چپ با سیستم چندزبانه (i18n)

## ساختار پروژه

| مسیر | توضیح |
| --- | --- |
| `build.js` | اسکریپت بیلد: ترکیب همه‌ی قطعات به یک فایل HTML |
| `parts/` | سورس ماژولار بازی (core, audio, levels, engine, player, enemies, render, ui, multi, ...) |
| `.github/workflows/deploy-pages.yml` | بیلد و انتشار خودکار روی GitHub Pages |

## انتشار اولیه (فقط یک بار)

۱. فایل `LUMORA-github-upload.zip` را دانلود و استخراج کنید (همه‌ی فایل‌های لازم، شامل `index.html` آماده، داخل آن است).
۲. در همین ریپو: **Code → Add file → Upload files** و همه‌ی فایل‌های استخراج‌شده را بکشید و رها کنید (روی مک با `Cmd+Shift+.` پوشه‌ی `.github` پیدا می‌شود)، سپس **Commit changes**.
۳. اکشن `Build & Deploy LUMORA` به‌صورت خودکار بیلد و منتشر می‌کند و آدرس بالای صفحه زنده می‌شود.

روش جایگزین بدون CI: فقط `index.html` را آپلود کنید و در **Settings → Pages** گزینه‌ی *Deploy from a branch* با برنچ `main` و پوشه‌ی `/ (root)` را انتخاب کنید.

## بیلد محلی

```bash
node build.js
```

خروجی در مسیر پیش‌فرض `LUMORA_Beyond_the_Layers.html` ساخته می‌شود (با متغیر محیطی `LUMORA_OUT` مسیر خروجی قابل تغییر است).

PeerJS در زمان بیلد داخل فایل نهایی جاسازی می‌شود. اگر `parts/_peerjs_lib.js` موجود نباشد، آن را دانلود کنید:

```bash
curl -fsSL https://unpkg.com/peerjs@1.5.4/dist/peerjs.min.js -o parts/_peerjs_lib.js
```

(در GitHub Actions همین کار به‌صورت خودکار انجام می‌شود؛ خود بازی هم هنگام اجرا اگر Peer موجود نباشد آن را از CDN لود می‌کند.)

## به‌روزرسانی بازی برای همه‌ی کاربران

سورس را در `parts/` تغییر دهید و به برنچ `main` پوش کنید؛ workflow به‌صورت خودکار بیلد و منتشر می‌کند و آدرس بازی همان قبلی می‌ماند — همه‌ی کاربران با یک رفرش نسخه‌ی جدید را می‌گیرند.
